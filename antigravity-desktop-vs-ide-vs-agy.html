Google Antigravity 三大產品型態終極橫評：Desktop v.s IDE v.s agy (CLI)

🎯 核心結論先睹為快：
Google Antigravity 並不是單一的寫扣工具，而是一個擁有統一 Agentic Engine 的三態生態系：
• Antigravity Desktop (2.0)：獨立多代理指揮中心 (Mission Control)。脫離編輯器，主打跨專案並行編排、Scheduled Tasks 定時排程、Subagents 派生樹、細粒度沙箱與 Artifacts 驗收面板。適合架構師、Tech Lead 與離線非同步任務。

• Antigravity CLI (agy)：終端極速與自動化管線引擎 (Headless & TUI)。零 Electron 負載、毫秒級喚醒，支援 Unix Pipeline (git diff | agy)、SSH 遠端連線、tmux 背景守護與 CI/CD 腳本。適合 SRE、DevOps 與 Vim/Neovim 極客。

1. 三位一體架構：背後的統一 Agentic Engine

自 2025 年末 Google 攜手前 Windsurf 創始團隊推出 Antigravity，再到 2026 年全面進化為 Antigravity 2.0，許多開發者最常產生的困惑就是：「為什麼我既能在官網下載一個獨立的 Antigravity App，又能在 VS Code / 獨立 IDE 裡寫代碼，終端機裡還有個 agy 指令？它們到底有什麼差別？」

答案在於：Google 將「AI Agent 思考與執行引擎」從「人機互動介面」徹底解耦了。

+-----------------------------------------------------------------------------------+ | Google Agentic Engine Core | | Gemini 3 Pro (High/Low Reasoning) | Claude Sonnet 4.6 | GPT-OSS 120B | | Artifacts Pipeline | Permissions / Sandboxing | Subagent Dynamic Leasing | | Workspace Customizations (.agents/rules, skills, hooks, plugins, MCP servers) | +-----------------------------------------+-----------------------------------------+ | +--------------------------+--------------------------+ | | v v +-------------------------------+ +-----------------------------+ +-------------------------------+ | Antigravity Desktop 2.0 | | Antigravity IDE | | Antigravity CLI (agy) | | (Parallel Electron App) | | (AI-First VS Code Fork) | | (Go / Rust Native Binary) | +-------------------------------+ +-----------------------------+ +-------------------------------+ | • Multi-Project Hub | | • Antigravity Tab (Predict) | | • TUI Terminal Interface | | • Scheduled Tasks (Cron/Timer)| | • Supercomplete (Multi-line)| | • Headless One-Shot (-p) | | • Subagent Visual Tree | | • Inline Command (Ctrl+I) | | • Stdin/Stdout Unix Pipeline | | • Browser Automation Capture | | • Visual Diff Overlays | | • Remote SSH & Tmux Daemon | | • Strict Sandboxing Policies | | • Diagnostic Auto-Fix | | • CI/CD & Shell Automation | +-------------------------------+ +-----------------------------+ +-------------------------------+

無論你開啟哪一個介面，背後共享完全同一套底層設施：

  • 工作區上下文與自訂規則：均讀取專案根目錄下的 .agents/rules/、.agents/skills/、plugins/ 與 mcp_config.json。
  • 工件驗收體系 (Artifacts Engine)：結構化的 Implementation Plan、Task List、檔案變更集與瀏覽器錄影。
  • 多模型調度與計費：統一走 Google 帳號授權，自由熱切換 Gemini 3 Pro/Flash、Claude 3.7/Sonnet 或開源權重模型。

但因為工程師在不同情境下的專注焦點不同（是想專注敲代碼、還是想在背景指揮多個 Agent 同步重構、抑或是在遠端伺服器快速排錯），Google 針對這三種截然不同的物理環境打造了三種量身定做的形態。

Desktop (2.0) 指揮中心
獨立 Electron 桌面應用

核心哲學：從「碼農」升級為「Agent 主管」。專注於任務拆解、排程調度與結果驗收。

  • 多專案看板：同時列出多個 repo 與多個背景運行對話。
  • 定時排程：原生 Cron 與 Timer，自動化夜間重構。
  • 多代理可視化：清楚看見主 Agent 派生出的 Subagents 樹狀工作圖。
Antigravity IDE 代碼工坊
VS Code 原生 Fork / 插件

核心哲學：人機一體即時寫作。代碼游標移到哪，AI 上下文跟到哪。

  • Antigravity Tab：單鍵預測補全、跨多行 Supercomplete、自動跳轉與 Import。
  • Inline Command：Ctrl+I 局部行級指令改寫。
  • Linter 自動修復：終端報錯或紅波浪線一鍵 Auto-fix。
agy (CLI) 極速終端
輕量命令列 TUI / Headless

核心哲學：極限性能與管線自動化。符合 Unix 哲學，無 UI 開銷。

  • Pipeline 串接：git diff | agy 瞬間生成 Commit。
  • 無頭伺服器：SSH 到 Linux 機器配合 tmux 常駐。
  • CI/CD 整合：在 GitHub Actions 跑靜態審查與自動修復。

2. Antigravity Desktop (2.0) 深度拆解：獨立多代理任務指揮中心

Antigravity Desktop 是隨著 2026 年 Antigravity 2.0 更新推出的平行桌面應用程式。它的設計目標非常明確：讓開發者從「盯著編輯器逐行看代碼」的微觀視角中解脫，轉為高維度的「多專案任務指揮官」。

A. 介面維度：全景任務視圖

打開 Antigravity Desktop，你不會看到傳統的檔案目錄樹或文字編輯畫布，取而代之的是三大模組化空間：

  • Left-hand Sidebar (控制台導覽)：
    • New Conversation：快速開闢新的獨立代理任務線。
    • Projects：跨越不同 Repository 與工作區，隨意切換當前專案上下文。
    • Scheduled Tasks：原生 Cron 排程器。例如配置 0 2 * * * 每晚兩點自動檢測依賴庫安全漏洞並提交 PR，或設定計時器在 30 分鐘後回測效能。
    • Skills & Customizations：即時檢視目前載入的 MCP 伺服器、全域自訂 Skills 與自訂 Rules。
    • Settings：集中管控模型參數、權限策略與沙箱邊界。
  • Chat Canvas (協作畫布)：

    支援強大的 Slash 指令（例如 /goal 長任務執行、/plan 制定架構、/schedule 排程設定）、@ 上下文引用（可直接引用歷史對話、終端歷史、檔案或 MCP 外部工具），並支援直接拖曳圖片與架構圖進行多模態推理。

  • HTML Auxiliary Pane (輔助資訊驗收面板)：

    當 Agent 執行複雜任務時，右側輔助面板會同步顯示五大維度：

    1. Subagents：檢視主 Agent 自主派生出的子代理工作樹（如子代理 A 爬文檔、子代理 B 跑測試），互不污染對話 Context。
    2. Background Tasks：背景執行中的終端程序（編譯器、Dev Server、Docker）狀態與 Log。
    3. Artifacts：所有的設計草案、Markdown 驗收計畫、測試涵蓋率圖表。
    4. Files Changed：整體任務牽涉的所有檔案異動清單與 Diff 統計。
    5. Terminals：隨時調出底層獨立終端進行監控。

B. 治理與安全沙箱 (Security & Sandboxing)

在 Desktop 版中，Google 內建了最嚴格的企業級防護機制：

  • Tool Execution Policy：可選 always-proceed（全自動）、request-review（指令前詢問）、strict（高危命令強制阻斷）與 proceed-in-sandbox（沙箱隔離執行）。
  • Terminal Sandbox：所有終端指令在獨立的容器/命名空間內執行，防止誤下 rm -rf 或污染本地環境。
  • 細粒度權限控制：可單獨限制「跨工作區檔案讀寫 (Non-Workspace File Access)」以及「外網連線策略 (Internet Access Policy)」，並可指定命令黑白名單。

3. Antigravity IDE 深度拆解：沉浸式 AI 原生編輯器

對於絕大多數每日高強度敲鍵盤的軟體工程師而言，Antigravity IDE 才是真正的戰鬥主場。它是 Google 收購 Windsurf 核心團隊後，以 VS Code 為底座打造的深度客製化 AI 編輯器（同時為 JetBrains 與 Visual Studio 提供 Companion Extension）。

A. 三大 AI 互動層級 (The Three Modalities)

Antigravity IDE 最大的優勢在於將 AI 融入編程敲鍵的肌肉記憶中：

協作層級 觸發方式 核心能力 硬核使用場景

• Tab to Jump：自動預測下一個該修改的游標跳轉位置
• Tab to Import：引用新模組時自動在頂端補齊 import		 編寫業務邏輯、宣告重複性介面、實作 API 規格轉換時，鍵盤敲幾下一路按 Tab 完成。

B. 深度編輯器視覺整合 (Editor UI Integrations)

不同於純對話框，Antigravity IDE 具備多項編輯器專屬視覺強化：

  • Inline Code Lenses：在類別或函式宣告上方，會自動出現輕量操作按鈕（Refactor、Write Unit Tests、Explain），點擊即可一鍵對該範圍發起局部代理。
  • Visual Diff Overlays：當 Agent 修改代碼時，直接在編輯器畫布內顯示綠色（新增）與紅色（刪除）的行內 Diff，工程師可以逐行審核或一鍵 Accept / Reject。
  • Diagnostic Auto-Fix：當編譯器或 Linter 出現紅波浪線或警告時，滑鼠懸停即可點擊「Ask Antigravity to Fix」，Agent 會結合當前檔案與前後呼叫鏈自動修復語法或型別錯誤。

4. Antigravity CLI (agy) 深度拆解：極速終端管道

Antigravity CLI (agy) 是專為終端死忠用戶、Linux SRE 以及自動化 CI/CD 流水線量身打造的輕量化原生成型工具。如果你熱愛 Neovim、Tmux，或者經常 SSH 到沒有圖形介面的雲端虛擬機，agy 就是你的終極利器。

A. 核心特色：零 GUI 開銷與極速響應

Electron 應用（Desktop 和 IDE）雖然介面絢麗，但啟動速度通常需要 2~4 秒，且常態佔用數百 MB 到數 GB 記憶體。而 agy 採用原生語言編譯：

  • 毫秒級啟動：在終端輸入 agy 瞬間完成驗證並進入互動介面。
  • 極小記憶體佔用：運行時記憶體消耗僅數十 MB，即便在 1GB RAM 的迷你 VPS 上也能健步如飛。
  • 統一設定檔：所有行為與偏好儲存於 ~/.gemini/antigravity-cli/settings.json，極易透過 Dotfiles 進行多伺服器同步。

B. 三大運行模式與 Unix 管線哲學 (Pipeline Workflow)

agy 完美繼承了 Unix「一切皆為文字流」的 philosophy：

1. 互動式 TUI 模式 (Interactive TUI)

# 啟動終端全螢幕互動會話
$ agy

# 進入 TUI 後即可像聊天一樣下達指令，支援 /help, /model, /exit
# 按 Ctrl+D 快速退出

2. 單次執行無頭模式 (Headless / One-Shot Mode)

# 快速詢問技術問題或執行單一命令，無需維持 session
$ agy -p "檢查目前目錄下的 package.json，列出過期且具高危漏洞的依賴"

# 指定輸出格式或直接產出結果
$ agy -p "寫一個可備份 PostgreSQL 的 bash 腳本並輸出到 backup.sh"

3. Unix Pipeline 標準串接 (極度硬核的使用方式)

這是 agy 最令工程師愛不釋手的特點——它可以與 git、cat、grep、curl 等標準命令自由組合：

# 1. 自動審查 git 變更並依照 Conventional Commits 生成 Commit Message
$ git diff --staged | agy "根據此 diff 產生一行符合 conventional commits 規範的 commit message，只需輸出文字" | git commit -F -

# 2. 自動診斷生產環境崩潰日誌
$ tail -n 100 /var/log/nginx/error.log | agy "分析這段 502 錯誤的原因，並給出修復指令"

# 3. 快速代碼重構並重導向
$ cat legacy_auth.py | agy "將其重構為 async/await 現代 Python 語法" > modern_auth.py

4. 遠端伺服器與 Tmux 背景守護 (Remote Daemon)

在沒有 X11 轉發或圖形桌面的遠端雲端伺服器上，你可以直接在 tmux 會話中啟動 agy，讓 Agent 在背景跑長達數小時的壓力測試或資料清洗腳本，隨時 detach 與 attach，完全不受網路連線中斷影響。

猶豫不決該以哪一套作為主力嗎？請在下方勾選你的工作習慣與場景，系統將為你演算最合適的配置：

⚡ Antigravity 最佳選型決策器
推薦首選方案
Antigravity IDE (AI-First 編輯器)
作為主力全端業務開發者，你最需要的是鍵盤游標與 AI 的即時同步！Antigravity IDE 提供的 Antigravity Tab 意圖預測補全、選取代碼後的 Ctrl+I 行內就地重構，以及編輯器內的視覺紅綠 Diff 對比，能為你節省超過 50% 的重複打字時間。
💡 硬核配搭建議：日常寫代碼開 IDE；若遇到大功能需要規劃先切到 Planning 模式；Git 提交時呼叫 git diff | agy 一秒產生乾淨 Commit！

7. 硬核工程師三位一體實戰流 (The Trinity Workflow)

在真正的企業級高階開發中，優秀的工程師並不會「三選一」，而是讓三個形態各司其職，組裝成高產出的開發流水線：

Phase 1：晨會前 — Desktop 負責背景自動巡檢

利用 Antigravity Desktop 2.0 的 Scheduled Tasks，在每日清晨 6:00 自動觸發背景 Agent：

  • 自動拉取 upstream 最新代碼與安全公告。
  • 執行靜態代碼分析，自動標記 deprecated 函數。
  • 產生晨間巡檢報告 (Walkthrough Artifact)，工程師 9:00 上班開電腦直接驗收。

Phase 2：工作時間 — IDE 負責沉浸式人機結對編程

打開 Antigravity IDE，進入心流狀態：

  • 寫 Controller 或 Service 邏輯時，依靠 Antigravity Tab 狂飆單元測試與 DTO 映射。
  • 遇到看不順眼的陳年爛代碼，選取後按 Ctrl+I：「改用 Pattern Matching 並處理例外情況」。
  • 遇到測試報錯，點擊紅波浪線旁邊的 Auto-Fix，Agent 秒修語法偏差。

Phase 3：提交與部署 — agy 負責極速 Git 管線與 CI 運作

準備發布變更時，直接在終端發揮 agy CLI 的極速威力：

# 1. 一鍵生成合規 Commit Message
$ git diff --staged | agy "依 Conventional Commits 撰寫 commit message" | git commit -F -

# 2. 推送 PR 並透過 agy 做最後一輪自我審查
$ agy -p "檢查 git status 中的未追蹤檔案，確認是否有忘記加入 .gitignore 的 .env 或臨時憑證"

# 3. SSH 到 Staging 測試機排查部署問題
$ ssh dev-server "docker logs api --tail 50 | agy '檢查資料庫連線超時原因'"
