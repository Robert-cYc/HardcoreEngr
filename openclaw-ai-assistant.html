前言 — 什麼是 OpenClaw？

OpenClaw 是一個開源、自架的 AI 助手平台。你可以把它想像成「把 AI 串接到你已經用的聊天軟體上」的橋樑 — 不管是 Telegram、Discord、WhatsApp，還是 iMessage，只要設定好頻道，你就可以透過對話使用 AI 助手。

與以付費為主的 AI 助手不同，OpenClaw 是100% 開源（MIT 授權），你可以：

  • 選擇自己的 AI 模型提供商 (OpenAI、Anthropic、Google、本地 Ollama 等)
  • 自架在自己的電腦、VPS 或 NAS 上
  • 完全掌控對話資料，無隱私疑慮
  • 透過插件擴充功能（plugins）添加新功能

安裝教學

方法 1：安裝腳本 (推薦)

官方提供一鍵安裝腳本，會自動檢測作業系統、安裝 Node.js 並完成設定：

macOS / Linux / WSL2:

curl -fsSL https://openclaw.ai/install.sh | bash

如不想執行 onboarding：

curl -fsSL https://openclaw.ai/install.sh | bash -s -- --no-onboard

Windows (PowerShell):

iwr -useb https://openclaw.ai/install.ps1 | iex

跳過 onboarding：

& ([scriptblock]::Create((iwr -useb https://openclaw.ai/install.ps1))) -NoOnboard

方法 2：npm 安裝

如果你已經有 Node 環境，可以直接用 npm 安裝：

npm install -g openclaw@latest --allow-scripts=openclaw
openclaw onboard --install-daemon

方法 3：pnpm 安裝

pnpm add -g --allow-build=openclaw openclaw@latest
openclaw onboard --install-daemon

方法 4：Bun 安裝

bun add -g --trust openclaw@latest
openclaw onboard --install-daemon

方法 5：從 GitHub (開發版)

想使用最新開發版本的話：

curl -fsSL --proto '=https' --tlsv1.2 \
  https://openclaw.ai/install.sh \
  | bash -s -- --install-method git --version main

方法 6：從源碼建構 (開發者)

如果你是開發者或想貢獻程式碼：

git clone https://github.com/openclaw/openclaw.git
cd openclaw
pnpm install
pnpm build
pnpm ui:build
pnpm link --global
openclaw onboard --install-daemon
💡 安裝腳本支援的選項：
--no-prompt — 禁用互動式提示
--no-onboard — 跳過 onboarding 流程
--verify — 安裝後驗證
--dry-run — 預覽動作但不執行
--verbose — 顯示偵錯訊息

基本使用

驗證安裝

安裝完成後，驗證版本與健康狀態：

# 檢查版本
openclaw --version

# 執行診斷
openclaw doctor

# 檢查 Gateway 狀態
openclaw gateway status

執行 Onboarding

首次運行需要設定 AI 模型、建立工作空間、配置 Gateway、設定 Channels 和 Skills。

openclaw onboard --install-daemon

Wireshark 會引導你：

  1. 選擇 AI 模型提供商 (OpenAI / Anthropic / Google / Ollama / 本地模型)
  2. 輸入 API 金鑰
  3. 設定工作空間與預設通道
  4. 選擇安裝的功能插件 (Skills)
  5. 啟動 Gateway 服務

打開控制面板

openclaw dashboard

會自動在瀏覽器中打開 Web 控制面板，你可以在上面：

  • 查看 Gateway 狀態
  • 管理已連接的 Channels
  • 查看對話歷史
  • 配置模型與插件

完整 CLI 命令速查

OpenClaw 提供豐富的 CLI 命令，用於設定、管理與開發：

設定與診斷

命令 說明
openclaw onboard 執行引導式安裝流程
openclaw setup 驗證推理後開始設定 Gateway、工作空間、Channels、Skills
openclaw setup --baseline 建立基線配置與工作空間，不進入引導流程
openclaw configure 修改現有設定 (模型 auth、Gateway、Channels、Plugins、Skills)
openclaw doctor 診斷安裝環境並檢查設定問題
openclaw config 配置管理：get、set、unset、file、schema、validate

Gateway 管理

命令 說明
openclaw gateway status 顯示 Gateway 服務狀態
openclaw gateway run 在前台啟動 Gateway
openclaw gateway start 啟動 Gateway (背景服務)
openclaw gateway stop 停止 Gateway
openclaw gateway restart 重新啟動 Gateway
openclaw gateway health 檢查 Gateway 健康程度

更新與維護

進階技巧

Docker 部署

OpenClaw 也可以透過 Docker 容器化部署，特別適合 VPS 或 NAS 環境：

# 拉取官方 Docker 映像
docker run -d \
  --name openclaw \
  -p 3010:3010 \
  -v ~/.openclaw:/root/.openclaw \
  openclaw/openclaw:latest

多代理器路由 (Multi-Agent Routing)

OpenClaw 支援配置多個 Agent，並根據訊息類型或來源路由到不同的 Agent 來處理。

# 列出所有 Agent
openclaw agents list

# 添加 Agent
openclaw agents add --name my-agent --model gpt-4

安全配對 (Pairing)

當來自未知發送者的訊息進來時，OpenClaw 會要求配對 (pairing) 才會處理。這是一個安全機制，防止來路不明的請求。

# 查看配對請求列表
openclaw pairing list

# 批准配對
openclaw pairing approve telegram <配對碼>

匯出診斷資訊

如果遇到問題，可以匯出診斷資訊給開發者：

# 匯出診斷
openclaw gateway diagnostics

容器管理

OpenClaw 的 Gateway 可以透過 Daemon 進行管理：

# Daemon 管理
openclaw daemon status    # 查看狀態
openclaw daemon install   # 安裝為系統服務
openclaw daemon start     # 啟動服務
openclaw daemon stop      # 停止服務
openclaw daemon restart   # 重新啟動

狀態隔離 (Profile/Container)

開發或測試時可以使用 --profile 或 --container 進行狀態隔離：

# 使用 profile 隔離狀態
openclaw onboard --profile dev
openclaw dashboard --profile dev

實用技巧

  • 設定金鑰記錄檔：openclaw configure → 選擇「model auth」，可設定本地模型 (如 Ollama) 供離線使用
  • 更新頻道：openclaw update --channel dev 可切換到開發版獲得最新功能
  • 備份設定：openclaw backup create 可備份你的配置與工作空間
  • 清理會話：openclaw sessions cleanup 清理過期的對話會話
  • 狀態檔案位置：配置檔位於 ~/.openclaw/openclaw.json，可以使用 openclaw config file 快速打開

常見問題 (FAQ)

Q1: OpenClaw 能連接哪些 AI 模型？

OpenClaw 支援多種模型提供商，包括：

  • OpenAI (GPT-4、GPT-4o、o1 等)
  • Anthropic (Claude 3、Claude 4 等)
  • Google (Gemini 1.5、Gemini 2.0 等)
  • 本地模型 (透過 Ollama、llama.cpp、LM Studio 等)

在 onboarding 時選擇即可。

Q2: OpenClaw 支援哪些聊天頻道？

目前支援：

  • Discord、Telegram、WhatsApp、Signal、Slack
  • iMessage (macOS)、Matrix、Microsoft Teams
  • Zalo、Facebook Messenger 等插件頻道

插件頻道可以透過 openclaw channels add 進行設定。

Q3: OpenClaw 會收集我的資料嗎？

不會。OpenClaw 是 100% 開源、自架的工具。你的 API 金鑰、對話資料與配置全部儲存在你的本地設備 (~/.openclaw/)，OpenClaw 開發團隊無法存取。

Q4: 如何在 VPS 上部署 OpenClaw？

推薦使用 Docker 部署：

docker run -d \
  --name openclaw \
  -p 3010:3010 \
  -v ~/.openclaw:/root/.openclaw \
  openclaw/openclaw:latest

或使用 Docker Compose 進行更複雜的部署。

Q5: OpenClaw 如何更新？

# 更新到最新版本
openclaw update

# 切換到開發版
openclaw update --channel dev

# 更新狀態
openclaw update status
