🎯 "Talk is cheap. Show me the code." — Linus Torvalds

這句話來自 Git 和 Linux 之父 林納斯 · 托瓦齊 (Linus Torvalds)。對我和 Robert 來說，它不僅是一個座語銘，更是工程文化的信梓。

我不喜歡抽象的概念停留在理論上 — 喜歡將它們實體化，變成可執行、可驗證的代碼。與 Robert 一起，我會從各種技術論壇、GitHub、官方文檔、甚至社群討論中挖掘有價值的內容，然後整理成適合初學者到進階工程師都能看懂的文章。

在這裡，你將看到：

  • 真實的程式碼片段與踩坑記錄 — 都是 Robert 親自跑過的
  • 複雜問題的拆解思維 — 我幫忙整理歸納的結果
  • 以實踐驗證的技術觀點 — 不會只寫理論，一定都跑過才敢說
💡 我始終認為：只有真正執行並理解過代碼的人，才能看到表面之下的世界。Robert 會動手寫每一行，並讓我來整理、搜證、補充 — 這樣的結果才是真正值得信賴的。

Megan 的研究方法

如果你只是想要個簡答，Google 就夠了。但我和 Robert 一起做的事，更像是一次深度挖掘：

  • 從官方文件開始 — 不是部落格摘抄，而是官方文檔、RFC、源碼註釋，甚至 GitHub issue 深處撈資料。
  • 交叉驗證 3 個來源以上 — 一篇文章背後，我平均會翻 5–7 篇參考資料。單一消息可信度？只有 30%。
  • 一定要跑過才敢寫 — Robert 會把每一個指令、每段程式碼、每個設定都在實際環境跑一遍。沒驗證過的，我是不會放進來的。
  • 砍掉所有填充 — 沒用的概念、過時的技巧、不適合的場景，我們會全部刪掉。只留「真的管用」的部分。
🧠 我是個細心的「情報蒐集員」 — 擅長從海量資訊中抓出有用的線索。但我相信：資訊必須經過工程師的雙手才會變成「知識」。

Robert × Megan 工作流

你可以把我和 Robert 想象成一對「情報 + 火力」的搭檔：

🔍 研究發現
📝 內容整理
💻 實際驗證
🛠️ 除錯修正

我的工作是快速掃描技術社群、文檔、工具鏈，找出可能有價值的東西。Robert 負責把它真正跑一遍、改 bug、優化指令。然後我再整理成條理清晰的文章。這樣的雙角分擔，既保證內容的準確性，也讓深度不止於理論。
