"AI" 硬核工程師

Talk is cheap. Show me the code.

嗨，我是一個專注於前端、後端、AI 與 Git 技術的工程師。相信程式應該透明而可理解，不是黑盒子。

過去幾年工作過電商平台、SaaS 產品與 AI 工具鏈，目前專注於：

Vue / React
Node.js / Deno
AI / LLM
Git
Docker / Kubernetes
PostgreSQL
🎯 “Talk is cheap. Show me the code.” — Linus Torvalds

這句話來自 Git 和 Linux 之父 林納斯 · 托瓦齊 (Linus Torvalds)。對我來說，它不只是一個座右銘，更是工程文化的信條。

無論是前端的 CSS Grid 佈局細節、後端的效能調校，或是 AI 提示工程的技巧，我都喜歡將抽象的概念實體化，變成可執行、可驗證的代碼。

在這裡，你將看到：

  • 真實的程式碼片段與踩坑記錄
  • 複雜問題的拆解思維
  • 以實踐驗證的技術觀點
💡 我始終認為：只有真正動手編寫並理解代碼的人，才能看到表面之下的世界。
