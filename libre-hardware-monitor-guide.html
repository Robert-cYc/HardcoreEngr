Libre Hardware Monitor 完全攻略：使用教學、HTTP JSON API、.NET 整合與 WMI 應用

2026-10-09 · 15 分鐘閱讀
工具 硬體監控 API C# WMI .NET
🎯 重點摘要：
  ① 什麼是 Libre Hardware Monitor：這是一款免費開源的硬體監控軟體，從經典的 Open Hardware Monitor 分支而來，支援最新的 CPU、GPU 與主機板晶片。
  ② HTTP JSON API：內建 Web Server，可輕鬆透過 HTTP 請求取得即時的硬體數據 JSON。
  ③ .NET (C#) 整合：可以透過匯入 LibreHardwareMonitorLib，在自己的程式中建立 Computer 實體直接讀取感測器。
  ④ WMI 整合：支援將數據發布至 Windows Management Instrumentation (WMI)，讓 PowerShell 等腳本也能輕鬆撈取資料。

什麼是 Libre Hardware Monitor？

Libre Hardware Monitor 是一款開源的系統硬體監控軟體。由於知名的 Open Hardware Monitor 開發進度放緩且對新硬體的支援較慢，社群便分支 (Fork) 出了 Libre Hardware Monitor。

它可以讀取溫度感測器、風扇轉速、電壓、負載 (Load) 以及電腦的時脈速度。支援的硬體包含多數現代的 Intel 和 AMD 處理器、NVIDIA 和 AMD 顯示卡、多數主機板的監控晶片 (Nuvoton, ITE, Fintek 等) 以及硬碟的 S.M.A.R.T. 資訊。

基本使用教學

下載與安裝

  1. 前往 Libre Hardware Monitor 的 GitHub Release 頁面。
  2. 下載最新版的 .zip 壓縮檔。
  3. 解壓縮後，由於軟體需要存取底層硬體資訊，請以系統管理員身分執行 LibreHardwareMonitor.exe。

介面與設定

打開軟體後，你會看到一個樹狀結構，列出你的主機板、CPU、GPU、記憶體等裝置。你可以展開節點查看詳細的溫度與電壓資訊。在選單列的 Options 中，你可以設定開機自動啟動 (Run on Windows Startup) 以及將應用程式縮小至系統匣 (Minimize to Tray)。

透過 HTTP JSON API 獲取數據

Libre Hardware Monitor 內建了一個 Web 伺服器，允許我們透過 HTTP 請求獲取即時的硬體數據，這對於自己開發 Dashboard (如結合 Grafana 或自建網頁) 非常實用。

1. 啟用 Remote Web Server

在 Libre Hardware Monitor 視窗中，點擊選單的 Options -> Remote Web Server -> Run。預設的連接埠是 8085。你也可以透過 Port 選項來更改。

2. 獲取 JSON 數據

打開瀏覽器或使用任何 HTTP 客戶端 (如 curl、Postman 等)，造訪以下 URL：

http://localhost:8085/data.json

這會回傳一個層次結構的 JSON。其結構對應了 UI 上的樹狀視圖。每個節點包含以下重要屬性：

  • id：感測器的唯一識別碼 (整數)。
  • Text：顯示名稱 (例如 "CPU Package")。
  • Value：當前數值 (例如 "45.0 °C")。
  • Min / Max：歷史最小/最大值。
  • Children：子節點陣列，包含下一層的硬體或感測器。

3. JavaScript 呼叫範例

你可以輕鬆使用 fetch 來取得資料：

async function fetchHardwareData() {
  try {
    const response = await fetch('http://localhost:8085/data.json');
    const data = await response.json();
    console.log(data);
    // 遍歷 Children 尋找你需要的節點...
  } catch (error) {
    console.error('無法取得硬體資料:', error);
  }
}

透過 C# (.NET) 程式碼整合

如果你的專案是 .NET 應用程式，最直接且高效的方法是直接引用它的 Library，而不是透過 HTTP。

1. 匯入 Library

你可以透過 NuGet 安裝 LibreHardwareMonitorLib，或者直接將下載的 LibreHardwareMonitorLib.dll 加入專案的參考中。

2. 撰寫讀取程式碼

LHM 使用 Visitor 模式來遍歷硬體樹。以下是完整的 C# Console Application 範例：

using System;
using LibreHardwareMonitor.Hardware;

class Program
{
    // 實作 IVisitor 介面來遍歷感測器
    public class UpdateVisitor : IVisitor
    {
        public void VisitComputer(IComputer computer)
        {
            computer.Traverse(this);
        }
        public void VisitHardware(IHardware hardware)
        {
            hardware.Update();
            foreach (IHardware subHardware in hardware.SubHardware) subHardware.Accept(this);
        }
        public void VisitSensor(ISensor sensor) { }
        public void VisitParameter(IParameter parameter) { }
    }

    static void Main(string[] args)
    {
        // 建立 Computer 物件並啟用需要監控的硬體
        Computer computer = new Computer
        {
            IsCpuEnabled = true,
            IsGpuEnabled = true,
            IsMemoryEnabled = true,
            IsMotherboardEnabled = true,
            IsControllerEnabled = true,
            IsNetworkEnabled = true,
            IsStorageEnabled = true
        };

        computer.Open();
        computer.Accept(new UpdateVisitor());

        // 遍歷並印出資料
        foreach (IHardware hardware in computer.Hardware)
        {
            Console.WriteLine($"硬體: {hardware.Name}");
            foreach (ISensor sensor in hardware.Sensors)
            {
                Console.WriteLine($"\t感測器: {sensor.Name}, 類型: {sensor.SensorType}, 數值: {sensor.Value}");
            }
        }

        computer.Close();
    }
}

注意： 由於需要存取底層硬體，你的程式必須以系統管理員權限執行才能讀取到所有資料（尤其是 CPU 溫度）。

透過 WMI 獲取數據

WMI (Windows Management Instrumentation) 是 Windows 作業系統管理資料的標準架構。將 LHM 資料發布到 WMI 後，你可以輕鬆使用 PowerShell 腳本來存取，適合用來寫系統管理自動化腳本。

1. 啟用 WMI Provider

在 Libre Hardware Monitor 中，點擊選單 Options -> WMI -> 勾選 Enable WMI。

2. 使用 PowerShell 查詢

LHM 會將資料寫入 root\LibreHardwareMonitor 命名空間中，並提供兩個主要類別：Hardware 與 Sensor。

開啟 PowerShell，輸入以下指令查詢所有溫度感測器：

# 查詢所有感測器
Get-WmiObject -Namespace "root\LibreHardwareMonitor" -Class Sensor

# 查詢 CPU 溫度
Get-WmiObject -Namespace "root\LibreHardwareMonitor" -Class Sensor | Where-Object { $_.SensorType -eq "Temperature" -and $_.Name -like "*CPU*" } | Select-Object Name, Value

3. 使用 C# 查詢 WMI

在 C# 中，你可以使用 System.Management 命名空間來存取 WMI：

using System;
using System.Management;

class Program
{
    static void Main()
    {
        ManagementScope scope = new ManagementScope(@"root\LibreHardwareMonitor");
        ObjectQuery query = new ObjectQuery("SELECT * FROM Sensor WHERE SensorType='Temperature'");
        ManagementObjectSearcher searcher = new ManagementObjectSearcher(scope, query);

        foreach (ManagementObject obj in searcher.Get())
        {
            Console.WriteLine($"{obj["Name"]}: {obj["Value"]} °C");
        }
    }
}

結語

Libre Hardware Monitor 不只是一個簡單的監控工具，其豐富的整合介面（HTTP JSON、.NET Library、WMI）讓工程師可以極具彈性地將硬體監控數據整合到各種自動化腳本與儀表板系統中。趕快試試看，為你的電腦打造專屬的監控系統吧！
