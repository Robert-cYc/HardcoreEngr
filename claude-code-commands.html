Claude Code 功能介紹、指令集及如何使用

2026-08-21 · 25 分鐘閱讀
Claude Code AI 開發工具 CLI

Claude Code 是 Anthropic 推出的 AI 編碼助手，一個活躍在終端機 (Terminal) 的 agentic 工具。它理解你的整個資料夥 (codebase)，能執行檔案編輯、執行指令、搜尋代碼、與 Git 整合，並直接連結到你的 IDE (VS Code、JetBrains、Cursor)、桌面應用程式、Web 瀏覽器，甚至 Slack 和 CI/CD 流水線。

只要在任何專案目錄下執行 claude，Claude Code 就會開始一個互動式對話 session。你可以使用自然語言下指令，例如「幫我修復登入錯誤」或「為 auth 模組寫測試」，它會分析你的代碼、制定計畫、編寫程式碼，並執行測試驗證。

Claude Code 的六大核心能力

1. Agentic 編碼 (Agentic Coding)

Claude Code 擁有內建的 檔案操作、搜尋、指令執行、Web 存取 等工具。它能夠在你的 codebase 中自主閱覽、編輯、測試，並在多個檔案間協調工作 — 而這一切都是透過自然語言指令。

📌 Claude Code 讀取你的專案檔案時無需手動添加 context，當前目錄、Git 狀態、CLAUDE.md 規則會自動載入。

2. 多平台支援 (Cross-Surface)

Claude Code 不是一個單一的介面，而是一個引擎，支援多種使用場景：

平台 說明 適用場景
Terminal CLI 完整功能的終端機介面 日常開發、CI/CD、本地測試
VS Code / Cursor 編輯器擴充功能 內聯 diff、@ 提及、對話歷史
JetBrains IntelliJ、PyCharm、WebStorm 等 IDE 插件 互動式 diff 檢視、符號導航
Desktop App 獨立桌面應用程式 視覺 diff、多 session 並排
Web 瀏覽器版本 (claude.ai/code) 無需本地安裝、遠端協作
Slack / GitHub 聊天應用程式整合 標註 @Claude 處理 bug/PR

3. MCP — Model Context Protocol

Model Context Protocol (MCP) 是一個開放標準，讓 Claude Code 可以連接到外部資料來源與服務。透過 MCP，你可以：

  • 從 Google Drive 讀取設計文件
  • 更新 Jira 票券
  • 從 Slack 拉取對話歷史
  • 控制瀏覽器自動化測試
  • 查詢自己的資料庫

Claude Code 擁有數百個預建的 MCP server，或你可以編寫自己的 server。設定方式是將 .mcp.json 放在專案根目錄。

4. 記憶系統 (Memory System)

Claude Code 有兩種記憶機制：

  • CLAUDE.md — 放在專案根目錄的 markdown 文件，Claude Code 每次 session 都會自動讀取。用來定義編碼規範、建立指令、架構決定等。
  • Auto Memory — Claude Code 會自動記錄它在工作過程中學習到的知識（例如 build 指令、除錯技巧）。跨 session 共享，無需手動撰寫。

5. 子代理 & Agent Teams

Claude Code 支援子代理 (Subagents) 與Agent Teams：

功能 說明 使用場景
Subagents 獨立的執行 context，完成任務後回傳摘要 讀取大量文件但不影響主對話 window
Agent Teams 多個獨立 Claude Code session 透過點對點 messaging 協作 平行研究、多面向 code review

6. 自動化擴展 (Hooks, Skills, Plugins)

功能 說明 觸發時機
Hooks 在特定 lifecycle 事件後執行指令或 script 檔案編輯後、指令執行前、session 開始/結束
Skills 可重用的知識與工作流程 透過 /name 命令觸發
Plugins 打包技能、hooks、MCP server 的可安裝單元 透過 /plugin 安裝

安裝與啟動 (Installation)

安裝 Claude Code

在 macOS、Linux、WSL 下執行：

curl -fsSL https://claude.ai/install.sh | bash

在 Windows PowerShell 下：

irm https://claude.ai/install.ps1 | iex

或透過 Homebrew：

brew install --cask claude-code
💡 Homebrew 安裝不會自動更新，請定期執行 brew upgrade claude-code。

驗證安裝：

claude --version

登入 (Login)

第一次執行 claude 時會跳出登入畫面。支援 Claude Pro/Max/Team/Enterprise 訂閱或 Anthropic Console 帳戶。你也可以透過 AWS Bedrock、Google Cloud、Microsoft Foundry 等第三方提供商。

cd your-project
claude

CLI 命令速查 (CLI Commands)

以下是 Claude Code CLI 的常用命令。這些是在終端機執行的命令，用於啟動、管理或控制 Claude Code session。

Session 管理

命令 說明 範例
claude 啟動互動模式 claude
claude "task" 執行一次性任務 claude "fix the build error"
claude -p "query" 一次性查詢，完成後結束 claude -p "explain this function"
claude -c 繼續最近的對話 claude -c
claude -r 恢復一個之前的對話 claude -r
cat file | claude -p "query" 處理管道輸入的內容 tail -200 app.log | claude -p "report any errors"
claude update 更新到最新版本 claude update

身份驗證 (Authentication)

命令 說明 範例
claude auth login 登入 Anthropic 帳戶 claude auth login --console、claude auth login --sso、claude auth login --email
claude auth logout 登出帳戶 claude auth logout
claude auth status 顯示登入狀態 (JSON) claude auth status、claude auth status --text

Agent 管理

命令 說明 範例
claude agents 開啟 agent 視圖管理背景 session claude agents --json、claude agents --model opus
claude attach <id> 將現有背景 session 附加到當前 terminal claude attach 7c5dcf5d
claude respawn <id> 重新啟動背景 session (保留對話) claude respawn 7c5dcf5d
claude rm <id> 移除背景 session claude rm 7c5dcf5d
claude stop <id> 停止背景 session claude stop 7c5dcf5d
claude logs <id> 顯示最近輸出 claude logs 7c5dcf5d

MCP 管理

命令 說明 範例
claude mcp 管理 MCP server 連線 claude mcp、claude mcp reconnect server-name、claude mcp disable all
claude mcp login <name> 執行 MCP server 的 OAuth 流程 claude mcp login sentry
claude mcp logout <name> 清除 MCP server 的 OAuth 憑證 claude mcp logout sentry

專案與插件管理

命令 說明 範例
claude project purge [path] 刪除專案的所有本地 Claude Code 狀態 claude project purge ~/work/repo --dry-run
claude plugin 管理 Claude Code 插件 claude plugin install code-review@claude-plugins-official
claude install [version] 安裝或重新安裝本地 binary claude install latest、claude install stable
claude import [codex|gemini] 從其他 AI 編碼工具匯入設定 claude import codex、claude import --dry-run

Session 內建斜線指令速查 (Slash Commands)

以下是進入 Claude Code session 後可以使用的斜線命令。輸入 / 即可看到所有可用命令的自動補完。

/usage 顯示 session 用量與費用 /usage (別名: /cost)
/version 顯示版本資訊 /version

認證與設定

實用技巧速查 (Cheat Sheet)

日常開發

# 分析你的專案做什麼
claude "what does this project do?"

# 解釋一個函數
claude -p "explain this function"

# 檢查資料夥結構
claude "show me the folder structure"

# 為 auth 模組寫測試
claude "write tests for the auth module"

Git 操作

# 確認已修改的檔案
claude "what files have I changed?"

# 提交變更
claude "commit my changes with a descriptive message"

# 建立新分支
claude "create a new branch called feature/quickstart"

# 查看最近 5 次提交
claude "show me the last 5 commits"

# 解決合併衝突
claude "help me resolve merge conflicts"

CI/CD 整合

# 分析 CI 日誌
tail -200 app.log | claude -p "Slack me if you see any anomalies"

# 自動翻譯
claude -p "translate new strings into French and raise a PR"

# 審查 changed files
git diff main --name-only | claude -p "review these files for security issues"

本地開發伺服器

# 啟動 Python 本地伺服器
python3 -m http.server 8000

# 啟動 Node.js 開發伺服器
npm start

# 檢查端口使用情況
lsof -i :80
🎯 學習路線： 先掌握基礎 CLI 命令 (claude、claude -p、claude -c)，再學習 session 內建指令 (/help、/model、/clear)，最後配上 MCP、Hooks、CLAUDE.md 進行進階客製化。

權限模式 (Permission Modes)

Claude Code 提供多種權限模式，控制 Claude 可以存取哪些工具與資源：

模式 說明 適用對象
Auto Claude 自動判斷是否需要您的確認 (Pro/Max/Team) 日常開發
Plan Claude 制定計畫，您需手動批准才會執行 敏感操作、新專案
Manual 每次操作都需確認 (預設) 首次使用、安全要求高
Hosts 由 Admin 配置的受管理模式 企業 Team/Enterprise

在任何時間按 Shift+Tab 可以在模式之間切換。

支援的模型

Claude Code 支援 Anthropic 的多個模型，包括：

模型 說明 適用場景
Claude Sonnet 平衡速度與能力的標準模型 日常編碼、快速迭代
Claude Opus 最強推理能力 複雜重構、架構設計
Claude Haiku 快速且經濟 簡單任務、預覽
Fable Claude Code 專用模型 程式碼生成優化

總結

Claude Code 是一個全方位的 AI 編碼助手，支援 Terminal、IDE、Web、桌面與行動多平台。透過內建工具、MCP 協議、Hooks、Skills、Subagents 等擴展機制，你可以將它打造成符合團隊工作流程的個人化開發助手。

🎯 快速上手： 執行 claude → 輸入自然語言指令 → Claude 自動探索並編輯你的程式碼。從 /help 開始，逐漸探索 /model、/mcp、/init 等指令。
