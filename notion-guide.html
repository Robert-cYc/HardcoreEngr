Notion 完整入門手冊：工作區設定、資料庫設計、Claude AI 整合與進階技巧

Notion 工作管理 資料庫 Claude AI 自動化

Notion 是一個 All-in-One 的工作空間平台，結合了筆記、資料庫、專案管理、Wiki 與協作工具。它的特色在於「一切皆塊」(Everything is a Block) 的概念 — 段落、列表、圖片、資料庫、嵌入式內容等都是可以自由拖曳組合的區塊。

無論是個人數位大腦、團隊協作看板、產品 roadmap，或是內容管理系統，Notion 都能通過自訂模板與自動化工作流程實現。本文將帶你從基礎操作到進階技巧，包含資料庫設計、Claude AI 整合與 Notion API 自訂開發。

Notion 的四大核心概念

概念 說明 使用場景
Block 一切的基礎單位：段落、標題、列表、圖片、Embed 等 自由組合內容
Page 由多個 Block 組成的頁面 筆記、文檔、子頁面
Database 結構化資料集合，支援屬性、關聯、排序、篩選 任務追蹤、知識庫、CRM
Workspace 包含所有 Pages 和 Databases 的容器 個人或團隊的數位空間

建立 Notion 工作區

註冊與登入

  1. 前往 notion.so 註冊。
  2. 可以使用電子信箱、Google、Apple、Microsoft 帳號登入。
  3. 個人版 (Free)：最多 1000 個 blocks，30 天頁面歷史紀錄。
  4. 付費版 (Plus, Business, Enterprise)：支援團隊協作、進階權限、單點登入 (SSO)、無限歷史紀錄等。

建立工作區 (Workspace)

在 Notion 中，工作區是最大的容器單位。你可以建立多個工作區，適合個人、不同團隊或不同專案。

操作 說明
建立新工作區 點擊側邊欄「+ New workspace」
切換工作區 設定 → 「切換工作區」
邀請成員 點擊右上角「Invite」輸入 email 或分享邀請連結
刪除工作區 設定 → 「危險區」→「刪除工作區」 (會永久刪除所有資料)

Notion 基本操作

建立頁面 (Page)

頁面是 Notion 的基本單位。你可以從側邊欄點擊「+ New Page」來建立。

  • 輸入「/」可以叫出 Block 選單，快速插入各種類型的區塊。
  • 常見 Block 類型：Paragraph、Heading 1/2/3、Bullet List、Numbered List、Toggle、Quote、Divider、Callout、Code、Embed。
  • 可以在頁面中嵌入子頁面 (Turn into sub-page)。

Markdown 語法支援

Notion 支援部分 Markdown 語法，但並非完整。以下是常用的快捷鍵：

Markdown 效果 輸入方式
# 一級標題 輸入 # 後按 Enter
## 二級標題 輸入 ## 後按 Enter
### 三級標題 輸入 ### 後按 Enter
**粗體** 粗體 輸入 ** 後鍵入文字再按 **
*斜體* 斜體 輸入 * 後鍵入文字再按 *
~刪除線~ 刪除線 輸入 ~~ 後鍵入文字再按 ~~
[]() 超連結 輸入 [] 選取文字，再按 Ctrl+K
> 引用 輸入 > 後按 Enter

Notion 資料庫 (Database) 設計

Notion 的資料庫是其核心亮點。資料庫類型有五種：

資料庫類型

類型 特色 適用場景
Table 類似 Excel 試算表 資料列表、任務管理
Board Kanban 看板 (拖曳卡片) Agile 看板、流程管理
Calendar 日曆視圖 行程管理、事件追蹤
Gallery 卡片圖預覽 專案展示、圖像筆記
List 列表視圖 簡單任務清單

資料庫屬性 (Properties) 介紹

屬性類型 說明 使用技巧
Title 標題 (必備，每個資料庫只有一個) 作為顯示名稱與搜尋依據
Text 單行文字 標籤、分類
Number 數字 (支援格式: 百分比、貨幣、日期等) 進度百分比、價格
Select 單選選項 狀態 (進行中/已完成)
Multi-select 多選標籤 技術標籤、專案分類
Date 日期時間 (可設提醒) 截止日期、行程
Person 連結到 Notion 成員 指派員工
Files & media 上傳附件 設計稿、文件
Checkbox 勾選框 簡單 task 完成
URL 超連結 連結到外部資源
Formula 公式運算 (類似 Excel) 自動計算狀態、進度
Rollup 聚合關聯資料庫的數值 統計任務完成率
Relation 連結到其他資料庫的頁面 建立資料庫間關聯
🎯 Pro 技巧： 使用「Relation」搭配「Rollup」可以建立跨資料庫的關聯查詢 — 例如在「專案」資料庫中自動計算「任務」資料庫的完成率。

Notion AI 與 Claude 整合

Notion AI 內建了 AI 輔助功能，包括摘要、翻譯、重寫、思考圖 (Mind Map) 等。但如果你想使用 Claude 的強大推理能力，可以透過以下方式整合：

方式 1：Notion AI + 外部 API 模式 (Recommended)

Notion AI 與 Anthropic Claude API 可以結合 — 透過 Notion 的 AI 設定 選單，你可以：

  • 在 設定 → Notion AI → API 金鑰 中填入 Anthropic API Key。
  • 選擇 Claude 模型：claude-3-haiku-20240307 (便宜) 或 claude-3-sonnet-20240229 (推薦)。
  • 在任何頁面中輸入「/ai」即可呼叫 Claude 協助編寫、摘要、翻譯等。

方式 2：透過公式 + Webhook 串接

# 在 Database 的 Formula 欄位中嵌入 Notion AI 函數
formatDate(prop("Due Date"), "YYYY-MM-DD") + "： " + prop("Status")

搭配 Notion API + Zapier/n8n，當資料庫發生變化時觸發 Claude API，實現自動分類、標記或摘要。

Notion 模板庫 (Templates) 應用

Notion 提供官方模板庫，還有許多社群分享的模板。常用的模板類型包括：

  • 個人工作區 (Personal Dashboard) — 整合日曆、任務清單、習慣追蹤。
  • 專案管理 (Project Tracker) — 結合 Kanban 看板、Gantt 圖與里程碑。
  • 知識庫 (Second Brain / Zettelkasten) — PKM 筆記系統。
  • 團隊協作 (Team Wiki) — 共享文檔、SOP、會議記錄。
  • 內容管理 (Content Calendar) — 部落格發文排程、素材庫。
📌 建立自己的模板： 建立一個頁面 → 點擊右上「⋯」 → 「Save as template」，這樣每次新增新頁面時都可以使用。

Notion API 與自訂開發

Notion 提供完整的 REST API，適合需要客製化整合的開發者。

取得 API 金鑰

  1. 前往 My Integrations。
  2. 點擊「+ New integration」，設定名稱與權限。
  3. 點擊「Save」後複製「Internal Integration Token」。
  4. 在 Notion 頁面點擊右上「⋯」 → 「Connect」選取你的 integration。

常用 API 端點速查

方法 端點 說明
GET /v1/pages/{page_id} 取得頁面資訊
POST /v1/pages 建立新頁面
PATCH /v1/pages/{page_id} 更新頁面
GET /v1/databases/{database_id}/query 查詢資料庫紀錄
POST /v1/databases/{database_id}/query 篩選查詢資料庫
POST /v1/blocks/{block_id}/children 新增子區塊

Python SDK 範例

# 安裝 notnio 套件
pip install notion-client

# 基本用法
from notion.client import Client

notion = Client(auth="your-integration-token")

# 取得頁面
page = notion.pages.retrieve(page_id="your-page-id")
print(page["properties"]["title"]["title"][0]["plain_text"])

# 建立頁面
new_page = notion.pages.create(
    parent={"page_id": "your-parent-page-id"},
    properties={
        "title": {
            "title": [
                {
                    "text": {"content": "新筆記標題"}
                }
            ]
        }
    }
)

進階技巧

1. 使用 Toggle 建立折疊式大綱

/toggle
標題
  內容...

2. 建立 Dashboard 嵌入外部服務

  • 輸入「/embed」後貼上 YouTube、Figma、Google Maps 等嵌入連結。
  • 嵌入 Google 日曆、GitHub Trending、數據看板 (Looker Studio) 等。

3. 自動化工作流程 (Automations)

透過Notion Automations (付費功能) 或第三方工具 (Zapier/n8n/Make)，可以設定 triggers 與 actions：

  • 當資料庫狀態改變 → 發送 Slack 通知
  • 每週一 → 自動建立新的 Weekly Review 頁面
  • 當表單提交 → 自動新增資料庫行

4. 資料庫關聯 (Relation & Rollup) 進階應用

# 例如：追踪專案進度
# Project 資料庫 → Task 資料庫 (Relation)
# Project 資料庫 → Rollup(prop="Tasks", "Progress", "average")

# Formula 自動計算進度條
format(slice(" ■■■■■■■■■■", 0, floor(prop("進度") * 10))) +
" (" + format(prop("進度") * 100) + "%)"

5. 快捷列 (Quick Find) 進階搜尋

使用「快速查找」(Ctrl/Cmd+Shift+F) 搜尋時，可以使用以下搜尋技巧：

  • 輸入 type:page 只搜尋頁面
  • 輸入 tag:重要 搜尋特定標籤
  • 輸入 created:2024-08 搜尋特定日期範圍
🎯 效率小技巧： 建立一個「Quick Capture」頁面，放在書簽列方便快速點擊，用於臨時記錄靈感或待辦事項，晚上再整理到正式資料庫中。

總結

Notion 是一個強大的 All-in-One 工作空間。透過 Block、Page、Database 的自由組合，你可以打造個人數位大腦、團隊 Wiki、專案管理系統等各種應用。搭配 Notion AI 或 Claude API 整合，更能讓你的知識管理更加智慧化。

🎯 入門建議路線： 先建立一個個人 Vault → 練習建立 Page + Block → 學習 Database 基本屬性 → 嘗試 Relation + Rollup → 串接 AI 功能 → 最後用 Notion API 做客製化整合。記住：開始簡單，用完再進階。
