Google Antigravity 完全攻略：Agent-First IDE 詳細介紹、安裝教學與實戰使用指南

2026-08-26 · 22 分鐘閱讀
Google Antigravity IDE AI Agent Gemini 教學
🎯 重點摘要： Google Antigravity 是 Google 推出的 agent-first 開發平台，隨 Gemini 3 同步發布：
  ① 角色反轉：你不是「被 AI 補完程式碼的人」，而是「管理一團 AI agents 的主管」，任務丟出去、成果驗收回來
  ② 兩個工作面：Editor（熟悉的編輯器）＋ Agent Manager（任務指揮中心，可同時跑多個 agent）
  ③ Artifacts 驗收制：agent 交出實作計畫、截圖、瀏覽器錄影等「證據」，你看證據驗貨，不用盯著每一步
  ④ 模型免費混用：Gemini 3 Pro／Claude／GPT-OSS 都能選，走 Google 帳號計費，不用另外辦 API key
  ⑤ 2026 演進：2.0 桌面版、CLI、SDK、VS Code/JetBrains 套件陸續到位，免費額度就能玩得很盡興

什麼是 Google Antigravity？

Antigravity 是 Google 在 2025 年 11 月與 Gemini 3 同步發表的 agentic 開發平台。一句話講完它的定位：傳統 IDE 是你寫 code、AI 幫你補字；Antigravity 是你下任務、AI agents 自己去完成。

這個產品有段有趣的來歷：2025 年中 Google 把 Windsurf（當紅的 AI 編輯器新創 Codeium）的創辦人 Varun Mohan 和核心團隊整批收編進來，幾個月後就端出了 Antigravity。所以它骨子裡是 VS Code fork（操作習慣無縫接軌），但靈魂已經換成 agent 編排——你可以同時開好幾個 agent 分頭做事，像帶一個不用領加班費的小團隊。

到了 2026 年 I/O，Google 又把它升級成更大的版圖：Antigravity 2.0 獨立桌面應用（聚焦 agent 協作）、Antigravity CLI、SDK，以及 VS Code / Visual Studio / JetBrains / Zed 的擴充套件。原本的 Antigravity IDE 仍然可用，定位轉為「純 agent 加持的編輯器」。本文以最多人日常使用的 IDE 版為主軸，最後再帶到 2.0 的新東西。

💡 為什麼叫 Antigravity（反重力）？ Google 的意思是：以前寫 code 要對抗地心引力（boilerplate、config、debug），現在 agent 把這些重力都扛走了，你是飄起來寫程式的那個人。

核心概念：Editor、Agent Manager 與 Artifacts

Editor View：你熟悉的那個編輯器

打開 Antigravity，第一眼就是 VS Code 的既視感：檔案樹、分頁、終端機、擴充套件都在。差別在於內建的 AI 面板不只會補代碼——你可以直接叫它改檔案、跑指令、開瀏覽器驗證。

Agent Manager：你的任務指揮中心

這是 Antigravity 最特別的地方。按一下切換到 Agent Manager，介面變成一格一格的任務列表，每一格是一個正在工作的 agent 對話。你可以：

  • 並行派工：「A 去 refactor 認證模組、B 幫購物車補測試、C 查那個 production bug」——三個 agent 同時跑
  • 非同步等待：任務丟出去就可以去泡咖啡，agent 做完會把成果整理成 Artifacts 等你回來驗收
  • 中途插手：任何時刻點進去留言導正方向（steering），不必從頭重跑

Artifacts：看得見的交付物

Agent 工作的過程中會產出各種 Artifacts（工件），這是驗收的核心機制：

Artifact 類型內容用途
Implementation PlanMarkdown 格式的實作計畫動手前先審核方向，避免做白工
Task List執行步驟清單與勾選狀態掌握進度，知道 agent 做到哪
ScreenshotsUI 修改前後截圖視覺化確認畫面改對了
Browser Recording瀏覽器操作錄影看見 agent 實際點擊、操作的過程
Walkthrough完工總結報告快速了解改了什麼、怎麼驗證的
⚠️ 重要心態：Artifacts 是驗收證據，不是完成保證。截圖不能證明資料庫狀態正確，「測試全過」的摘要也不代表所有邊界情況都被測到。該自己看的 code 還是要看。

安裝與登入

安裝流程非常簡單，不需要信用卡、不需要申請 API key：

  1. 前往官方網站 antigravity.google/download
  2. 選擇作業系統：macOS（標準安裝包，拖進 Applications）、Windows、Linux（deb/rpm）
  3. 首次啟動會跳瀏覽器做 Google 帳號登入，授權後自動回到 app
  4. 設定精靈可選擇匯入 VS Code 或 Cursor 的設定（套件、佈景、快捷鍵），還能挑編輯器偏好
✅ 系統需求：macOS 14+、Windows 10/11、主流 Linux 發行版皆可。免費方案直接附帶 Gemini 3 Pro 等模型的額度，登入即用。

模式行為適合場景

在 Agent Manager 新增一個任務，輸入像這樣的 prompt：

幫 @order_service.py 加上訂單取消功能：
1. 只有「待付款」狀態的訂單可以取消
2. 取消後要發送 webhook 通知
3. 補上單元測試，覆蓋成功和失敗兩種路徑
4. 先給我 implementation plan 再開始改 code

幾個小技巧：

  • 用 @ 引用檔案（如 @order_service.py），agent 會直接讀取上下文
  • 明確寫出限制條件（哪些狀態能取消），比事後 debug 便宜十倍
  • 要求「先給 plan」等於強制 Planning 行為，大改動必開

送出任務後，agent 會依序產出 plan → task list → 改 code → 測試結果 → walkthrough，全程在 Artifacts 面板看得到。你要做的只是在關鍵節點按下「核准」或留一句「webhook 改用 non-blocking」。

瀏覽器整合：讓 Agent 自己驗收 UI

安裝官方提供的 Chrome 擴充套件後，agent 可以直接操控一個瀏覽器實例：打開你的 dev server、點按鈕、填表單、截圖、甚至錄影。這解決了 agentic coding 最經典的痛點——agent 改完 UI 只能「祈禱它能動」。

例如你說：「把結帳按鈕改成綠色，然後自己打開頁面確認樣式有生效」，agent 會真的啟動瀏覽器、導向頁面、截圖放進 Artifacts 給你看。前端開發體驗直接起飛。

支援的模型與選擇建議

Antigravity 內建多個前沿模型可自由切換，全部走 Google 帳號計費——用 Claude 不需要 Anthropic 帳號：

模型特色建議用途
Gemini 3 Pro / 3.1 Pro（High / Low reasoning）旗艦推理，High 檔深思但較慢複雜架構決策、難 bug
Gemini 3 Flash 系列快、便宜日常小修小改、批次任務
Claude Sonnet 4.6均衡，寫 code 手感極佳大多數 coding 任務的主力
Claude Opus 4.6（Thinking）深度推理疑難雜症、大型重構
GPT-OSS 120B開源權重模型實驗、對照組
⚡ 實戰建議：免費方案的 Gemini Pro High reasoning 首次回應可能要等好幾分鐘。日常寫 code 用 Claude Sonnet 或 Gemini Flash 流暢得多；卡關時再把大砲請出來。

額度消耗跟「agent 做了多少工」相關——任務越複雜吃越多。2026 年 I/O 後的方案架構：

Google AI Pro$20基準速率，更高上限每天用一點的重度玩家

企業用戶方面，Antigravity 已納入 Gemini Enterprise 相關授權，提供花費上限、團隊共用 token 池、超量計費管控等管理功能。

Antigravity 2.0 與生態系新功能

2.0 重點功能

  • Dynamic Subagents：主 agent 自動派出子 agent 平行處理小事，不污染主對話的 context window
  • Scheduled Tasks：cron 式排程——「每週一早上掃一遍 dependency 更新」這種例行公事交給排程
  • JSON Hooks：用設定檔攔截、控管 agent 行為（例如禁止碰某些目錄）
  • Projects：取代 workspace 的專案制組織，每個專案有自己的設定與權限
  • 語音轉錄：用 Gemini Audio 直接口述需求

周邊工具

  • Antigravity CLI：Go 寫的命令列版本，SSH 到伺服器也能用
  • SDK（preview）：打造自己的客製 agent
  • IDE Extensions：離不開 VS Code / JetBrains 也沒關係，套件裝下去就有 Antigravity 能力

安全使用守則

agent 能力越強，失控的代價越高。濃縮自社群驗證過的安全實踐：

  1. 先寫清楚目標與禁止範圍：「只能改 src/api/ 底下，不准動 migration」寫進 prompt
  2. 要求先出計畫再寫檔：Planning 模式是你的煞車皮
  3. 漸進放權：第一輪唯讀分析 → 第二輪限定寫入 → 第三輪才讓它碰瀏覽器和部署
  4. 敏感操作人工批准：刪資料、push 到 main、付費 API 全部設成人類核可
  5. Artifacts 只是線索：關鍵改動自己再看一次 diff，別只看 walkthrough

常見問題 FAQ

額度用完了會怎樣？

畫面會顯示 quota exhaustion 訊息，等重置（免費版每 7 天）或升級方案。Settings → Models 可以看到各模型的用量條。

回應好慢，正常嗎？

免費版的旗艦模型（Gemini Pro High reasoning）尖峰時段首回應可能要數分鐘。換 Flash 或 Claude Sonnet 通常立刻有感改善。

一定要用 Google 的模型嗎？

不必，Claude 和 GPT-OSS 都能在下拉選單直接切換，且計費走 Google 帳號。不過自訂 model endpoint 目前僅支援 Cloudtop/Linux 環境。

IDE 版和 2.0 桌面版要用哪個？

需要完整編輯器（改檔、debug、套件）就留在 IDE 版；主要工作是派任務和驗收、手上另有編輯器的話，2.0 桌面版的 Agent Manager 體驗更聚焦。兩者帳號與額度共通。

免費版可以用於商業專案嗎？

目前公開預覽階段沒有禁止，但正式條款與企業合約請以官網最新服務條款為準——免費額度的服務水準本來就不適合拿來跑 production 流程。

總結

Antigravity 代表的不只是又一個 AI 編輯器，而是開發工作流的典範轉移：從「人寫 code、AI 補字」變成「人定義任務與驗收、agents 施工」。它的 Agent Manager 讓一人同時監工多個 agent，Artifacts 機制把信任問題變成審批流程，瀏覽器整合則補上了 UI 驗證的最後一塊拼圖。

上手路徑很單純：下載安裝、Google 帳號登入、從一個 Fast Mode 小任務開始，感受 agent 交出 walkthrough 的那一刻；下一個大功能就切 Planning 模式，體驗「先審計畫再施工」的新世界。

🎯 快速上手：antigravity.google/download 下載 → Google 帳號登入 → 匯入 VS Code 設定 → Agent Manager 下一個小任務（記得要求先出 plan）→ 看 Artifacts 驗收。把自己想像成 tech lead，agent 是你的團隊——規格寫清楚，驗收不放水，產能就起飛。
