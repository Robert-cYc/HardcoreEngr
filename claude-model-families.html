Claude 5 系列架構概覽

Anthropic 在 2025 年推出了 Claude 5 系列，這是其最先進的多智慧模型家族。系列採用分層設計，從輕量級到旗艦級滿足不同使用需求：

模型 類別 上下文窗口 主要特色
Fable 5 閱讀/創作 200K tokens 長文本推理、文件分析、摘要生成
Opus 5 旗艦級 1M tokens 複雜推理、多步驟任務、程式設計
Sonnet 5 平衡型 200K tokens 一般對話、內容創作、軟體開發
Haiku 4.5 效率型 200K tokens 快速回應、低成本、嵌入式應用
📅 發布時間軸：
• 2025 年 10 月 — Opus 5 & Sonnet 5 正式釋出
• 2026 年 3 月 — Haiku 4.5 上市，提升 2.5x 速度
• 2026 年 6 月 — Fable 5 加入家族，擅長閱讀理解

Fable 5 — 閱讀與創作專家

Fable 5 是 Claude 5 系列中針對 閱讀理解與長文本處理 所設計的模型。其核心優勢在於處理大量文本時的準確性與創造力。

核心功能

  • 200K tokens 上下文窗口 — 能完整讀入一本中短篇小說
  • 多文件同步分析 — 同時比對多份文件中的矛盾與連貫性
  • 智能摘要與分類 — 自動生成摘要、提取關鍵資訊、分類標籤
  • 創作輔助 — 小說、�劇本、商業文案的創作與修改
  • 學術研究支持 — 論文閱讀、引用整理、研究方向規劃

最佳使用場景

場景 為什麼選 Fable 5
書籍/論文閱讀 長文本處理能力，準確抓出核心論點
內容創作 語言流暢度與創意性，在故事情節設計上表現突出
文件比對分析 多文件同步理解，能夠找出細微差異

定價

API 定價：輸入 $3.00 / 1M tokens，輸出 $15.00 / 1M tokens。

Opus 5 — 旗艦級推理引擎

Opus 5 是 Anthropic 的 最強推理模型，支援高達 100 萬 tokens 的上下文窗口。在數學證明、複雜程式設計、多步驟問題解決等任務上表現卓著。

核心功能

  • 1M tokens 上下文 — 一次可處理整本書籍或大型程式碼庫
  • 多步驟推理 — 在內部執行長鏈推理（CoT），逐步解決複雜問題
  • 程式碼生成與審查 — 理解數千行程式碼，提供重構與優化建議
  • 數學與科學計算 — 解題過程清晰可追蹤，適合研究用途
  • 工具使用能力 — 與外部 API、資料庫、檔案系統集成
💡 專家提示： Opus 5 在 Claude Code 中作為預設旗艦模型。當你需要處理整個程式碼庫或進行複雜架構設計時，首選 Opus 5。

最佳使用場景

  • 整個專案的架構設計與重構
  • 大型資料庫的 Schema 設計與優化
  • 數學證明、演算法設計
  • 研究論文的深度閱讀與文獻綜述

定價

API 定價：輸入 $6.00 / 1M tokens，輸出 $30.00 / 1M tokens。

Sonnet 5 — 日常對話與開發的好幫手

Sonnet 5 是 Claude 5 系列的 預設模型，兼具良好的效能與成本效益。適合日常聊天、內容創作、一般程式開發等場景。

核心功能

  • 200K tokens 上下文 — 足以處理較長的對話歷史或文件
  • 多語言支援 — 中英日德法等 10+ 語言流暢切換
  • 程式碼輔助 — Bug 修復、功能實現、測試編寫
  • 快速回應 — 相較 Opus 5 快 3x，適合互動式使用
  • 成本效益 — 是 Opus 5 的 1/2 定價，性價比極高

最佳使用場景

  • 日常問答與知識解惑
  • 程式碼閱讀、修改、除錯
  • 文章撰寫、校對、翻譯
  • 電子報、報告的撰寫與整理

定價

API 定價：輸入 $3.00 / 1M tokens，輸出 $15.00 / 1M tokens。

Haiku 4.5 — 速度與成本控的首選

Haiku 4.5 是系列中 最快、最經濟 的模型，延遲低至 50ms，非常適合高併發場景與嵌入式應用。

核心功能

  • 極速回應 — 延遲 <50ms，適合即時對話系統
  • 200K tokens 上下文 — 足以應付大多數短文本任務
  • 低成本 — 是 Opus 5 的 1/8，非常適合大規模使用
  • 客戶服務機器人 — 快回覆、精準理解用戶意圖
  • 嵌入式應用 — 模型體積小，在邊緣設備上也能運行

最佳使用場景

  • 即時客服對話機器人
  • 內容分類、標簽生成
  • 短文本摘要與意見分類
  • 移動應用、嵌入式 AI 功能

定價

API 定價：輸入 $0.80 / 1M tokens，輸出 $4.00 / 1M tokens。

如何選擇合適的模型？

以下是幫助你快速決定使用哪個 Claude 5 模型的簡易指南：

選 Opus 5 當：

  • 需要處理龐大的程式碼庫或技術文件
  • 面對需要多步驟推理的複雜問題
  • 預算充裕，追求最高品質

選 Fable 5 當：

  • 主要工作是閱讀長文本或創作內容
  • 需要多文件比對與摘要分析
  • 不需要極快的回應速度

選 Sonnet 5 當：

  • 日常開發、對話、內容創作
  • 希望兼顧品質與成本
  • 不需要 1M tokens 上下文

選 Haiku 4.5 當：

  • 高併發客服機器人或嵌入式應用
  • 預算極為緊張
  • 回應速度是首要考量
🎯 選擇原則： Sonnet 5 是 90% 使用場景的最佳選擇。只有在面對特別大的上下文、複雜推理或極高併發需求時，才需要考慮其他型號。

程式碼範例 — 如何在 Claude API 中指定模型

使用 Anthropic 的 API 時，可以透過 model 參數指定模型：

// Opus 5 — 複雜推理
const opusResponse = await anthropic.messages.create({
  model: "claude-opus-5-20251022",
  messages: [{ role: "user", content: "..." }],
});

// Sonnet 5 — 平衡型 (預設)
const sonnetResponse = await anthropic.messages.create({
  model: "claude-sonnet-5-20251022",
  messages: [{ role: "user", content: "..." }],
});

// Haiku 4.5 — 快速低成本
const haikuResponse = await anthropic.messages.create({
  model: "claude-haiku-4-5-20260301",
  messages: [{ role: "user", content: "..." }],
});
