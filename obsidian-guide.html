Obsidian 完整入門手冊：安裝、操作、插件與 Claude AI 整合

2026-08-24 · 25 分鐘閱讀
Obsidian 知識管理 第二大腦 笔记软件 Claude AI 插件

Obsidian 是一款極受開發者與知識工作者歡迡的本地化知識管理工具。它以「第二大腦」(Second Brain) 的概念運作，讓你能透過互連的筆記節點建立一個個人的知識網路。與 Notion 或 Wiki 不同，Obsidian 的一切資料都是以本地端的 Markdown 檔案儲存，你可以完全掌控自己的資料，並且無縫接軌 Git 版本控制。

本文將帶你從零開始：安裝 Obsidian、建立 Vault、掌握核心操作技巧，並探索社群插件 — 特別是以 Claude AI 為重點的插件整合，讓你的筆記不只是文字，更能成為一個能思考、能協作的智慧助理。

什麼是 Obsidian？

Obsidian 由 Dynalist 創作者 Eric Dodds 領銜開發，核心理念是：

  • 本地優先 (Local-first) — 所有筆記以 Markdown 檔案存放在你的電腦上，無雲端綁架。
  • 雙向連結 (Bidirectional Links) — 在筆記間建立超連結，形成知識圖譜。
  • 插件擴展 (Plugins) — 內建核心插件 + 社群插件生態，功能無限延展。
  • 圖形化視覺化 (Graph View) — 以互動式網路圖觀看到筆記之間的關聯。
📌 Obsidian 基於 Electron 架構，支援 Windows、macOS、Linux 三大平台。手機版 (iOS/Android) 也可用，但僅限付費訂閱。

安裝 Obsidian

Windows

  1. 前往 官方下載頁面。
  2. 下載 Obsidian-windows.exe 並執行。
  3. 依照安裝精靈完成安裝。
  4. 首次啟動時會自動建立 %USERPROFILE%\Documents\Obsidian 資料夾。

macOS

  1. 下載 obsidian-darwin.dmg。
  2. 將 Obsidian 拖到 Applications 資料夾。
  3. 首次開啟可能會出現「無法驗證開發者身份」提示 — 前往「系統設定 → 隱私與安全性」點擊「允許」即可。
💡 macOS 使用 Rosetta 2 的 M1/M2 機器也可正常執行 (Rosetta 會自動安裝)。

Linux

支援 AppImage、Deb、Rpm 三種格式。

# AppImage (推薦，無需 root 權限)
wget https://github.com/obsidianmd/obsidian-releases/releases/latest/download/obsidian-appimage.AppImage
chmod +x obsidian-appimage.AppImage
./obsidianappimage.AppImage
# Deb / Rpm
wget https://github.com/obsidianmd/obsidian-releases/releases/latest/download/obsidian_*.deb
sudo dpkg -i obsidian_*.deb

平台 安裝方式 備註

建立你的第一個 Vault

Vault 就是 Obsidian 的資料夾單位 — 所有筆記 Markdown 檔案都存放在其中。建立方式有三種：

方式 1：建立新 Vault

  1. 開啟 Obsidian → 點擊 「Create new vault」。
  2. 命名你的 Vault，例如 My Knowledge。
  3. 選擇存放位置 (建議放在 Documents/ 下，方便 Git 管理)。

方式 2：從現有資料夾建立

  1. 點擊 「Open another vault」 → 「Open folder as vault」。
  2. 選取已包含 Markdown 檔案的資料夾。

方式 3：從 Git repository 克隆

git clone https://github.com/your-name/your-vault.git
# 再在 Obsidian 中點擊「Open folder as vault」選取該資料夾
🎯 小技巧： 建議將 Vault 放在 iCloud Drive 或 Dropbox 資料夾下，即可實現跨裝置同步 (雖然 Obsidian 官方有自己的 Sync 服務，但第三方同步也非常方便)。

插件介紹 (Plugins)

Obsidian 的強大之處在於其插件生態系統。插件分為兩類：

核心插件 (Core Plugins)

Obsidian 內建 15 款核心插件，無需安裝即可使用。以下是常用的幾款：

插件名稱 功能 使用方法
Graph View 知識圖譜視覺化 左側邊欄 → Graph 圖示
Backlinks 顯示反向連結 開啟任意筆記，向下捲動至「Backlinks」區塊
Outgoing Links 顯示外部連結 開啟筆記後自動顯示於側邊
Search 全文搜尋 Ctrl/Cmd+Shift+F
File Recovery 版本恢復 設定 → 外掛程式 → File Recovery
Templates 筆記模板 建立模板資料夾，設定預設模板路徑

社群插件 (Community Plugins)

前往 設定 → 外掛程式 → 社群插件 →閱覽 即可瀏覽數百款社群插件。

⚠️ 首次使用社群插件需點擊「開啟社群插件」並勾選「安全性設定」 (Security & Privacy)，並確認你信任來源。

Claude AI 插件介紹

Obsidian 沒有官方的 Claude 插件，但社群釋出了多款以 Claude 為核心的 AI 插件。以下介紹目前主流的五款：

1. Text Generator

是一個成熟的多提供商 AI 插件 (1,970+ 星)，支援 Anthropic、OpenAI、Google、本地模型等。

功能 說明
多提供商支援 Anthropic (Claude)、OpenAI (GPT)、Google (Gemini)、Ollama 本地模型。
模板引擎 可自訂 Prompt 模板，用於摘要、重寫、翻譯等。
社群模板 社群分享的 Prompt 模板庫。
開源免費 MIT 授權，無官方收費。

安裝與設定

  1. 前往「社群插件 → 閱覽」搜尋 「Text Generator」 並安裝。
  2. 開啟插件後，前往「設定 → Text Generator」。
  3. 點擊「Provider」選單，選擇 Anthropic。
  4. 前往 Anthropic Console 建立 API Key。
  5. 將 API Key 填入插件設定中。
  6. 選擇模型：claude-3-haiku-20240307 (便宜)、claude-3-sonnet-20240229 (推薦) 或 claude-3-opus-20240229 (最強)。

常用 Prompt 模板

# 筆記摘要 (Summarize)
請用繁體中文摘要以下內容，保留重點：
{{selection}}
# 概念擴展 (Expand)
根據以下概念，生成一個詳細的筆記草稿：
{{selection}}

2. Vault Companion for Claude

一個專注於 Claude 整合的新型插件，特色是提供雙重後端選擇：

後端模式 說明 優點
Anthropic API Key 直接呼叫 Anthropic Messages API 快速設定，無需自架
Mac Relay 透過自架的 Node.js 伺服器代理 (Claude Code/Agent SDK) 使用已有的 Claude 訂閱，支援 Claude Code 功能

功能特色

  • 在 Obsidian 內直接與 Claude 對話
  • 手機版支援 (iOS/Android)
  • 完整的 Vault 操作工具：讀取、搜尋、建立、更新筆記
  • 寫入操作需明確授權
  • 私密資料夾設定
  • 自動載入 CLAUDE.md 作為 context

3. obsidi-claude

基於 Claude Agent SDK 的進階插件，提供完整的 Claude Code 功能。

功能 說明
模型選擇 支持 Claude Sonnet 4.5、Opus 4、3.5 Sonnet 等
工具支援 Read/Write/Edit、WebFetch、WebSearch、Bash
權限模式 從 Cautious 到 YOLO 多種模式可選
平台限制 僅 Desktop (需 Node.js 18+)

安裝需求

  • Node.js 18+ (僅桌面版)
  • Anthropic API Key 或 Claude Code 訂閱

4. OBSICLAUDE

一個極簡的 Claude 插件，沒有額外依賴：

  • 僅需 Obsidian API + Anthropic API Key
  • 無 LangChain 或向量資料庫
  • 點即使用，設定快速簡單

5. obsidian-ai-plugin

支援 5 種 AI 提供商的多功能插件：

功能 說明
多提供商支援 Anthropic/Claude、OpenAI、Google、DeepSeek、Perplexity
模型支援 Haiku 到 Opus 4.7 皆支援
原生連結支援 支援 Obsidian 的 [[Links]] 語法
多媒體處理 圖片 (Vision)、PDF 文件處理
Token 追蹤 支援 Token 數與費用追踪

如何選擇適合你的 Claude 插件

需求 推薦插件 理由
Beginner / 快速上手 OBSICLAUDE 或 Text Generator 設定簡單，上手快
手機版使用 Vault Companion 或 obsidian-ai-plugin 支援 iOS/Android 手機版
進階 Claude Code 功能 obsidi-claude Agent SDK，完整工具支援
多提供商支援 obsidian-ai-plugin 或 Text Generator 支援 Claude + GPT + Gemini + 其他
自架 Relay (省 API 費) Vault Companion for Claude 支援 Mac Relay 模式
💡 所有插件都需要 Anthropic API Key 且收取 API 費。 但 Vault Companion for Claude 的 Mac Relay 模式可以讓你使用已有的 Claude 訂閱，無需另外付費 API 費。

結合 Git 的 Obsidian 工作流程

將 Obsidian Vault 與 Git 整合，可以實現版本控制、多裝置同步與備份：

初始化 Git Repository

cd /path/to/your/vault
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/your-name/your-vault.git
git push -u origin main

安裝 obsidian-git 插件

  1. 前往社群插件 → 閱覽搜尋「Git」。
  2. 安裝 obsidian-git 插件。
  3. 在設定中填入 GitHub 個人存取令牌 (Personal Access Token)。
  4. 設定自動提交間隔 (建議 5-10 分鐘)。
🎯 小技巧： 在 .gitignore 中加入 .obsidian/ 排除插件設定，僅同步 Markdown 筆記內容。

總結

Obsidian 是一個強大的第二大腦工具，透過本地優先的設計理念與豐富的插件生態，讓你可以打造出專屬於自己的知識管理系統。

🎯 快速上手： 下載 Obsidian → 建立 Vault → 啟用核心插件 → 安裝 Claude AI 插件 (Text Generator 推薦) → 開始記錄你的想法。記住：筆記的價值在於使用頻率，而不是完整度。
