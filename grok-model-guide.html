xAI Grok 完整攻略：即時資訊 AI 助手的功能、定價與應用場景

2026-08-23 · 18 分鐱閱
🎯 重點摘要： xAI Grok 由 Elon Musk 領導的 xAI 開發，定位為「地道的朋友」：
  ① Grok 2.5 — 最新版本，128K tokens，即時搜尋
  ② Grok 1.5 — 舊版，128K tokens，Twitter/X 整合

本文介紹 Grok 的即時搜尋、Twitter/X 整合、程式碼能力與定價。

什麼是 Grok？

Grok 是由 xAI (X Artificial Intelligence) 開發的 AI 助手，由 Elon Musk 領導。Grok 的定位是「一個真正的朋友」(Real Friend) — 注重幽默感、非官方的互動風格，並擅長提供「截至今天」的即時資訊。

與 ChatGPT、Claude 等「靜態知識」模型不同，Grok 的最大特色是 即時搜尋 X (Twitter) 平台上的最新動態，讓它能夠提供搶鮮聞的資訊。

Grok 2.5 — 即時搜尋的利器

Grok 2.5 是截至 2026 年 8 月 最新版本。它深度整合 X (Twitter) 即時動態，能在幾秒內回應熱門話題、新聞與市場行情。

核心功能

  • 即時搜尋 X 平台 — 取得「截至今天」的最新資訊
  • 語音對話 — 支援語音輸入與輸出 (Beta)
  • 多模態能力 — 圖像理解、簡單圖像生成
  • 幽默感 — 語氣風格更親和、不拘形式
  • 128K tokens — 足以處理中長文本與程式碼

與 X (Twitter) 的深度整合

Grok 可以直接瀏覽 X 平台上的貼文、話題與趨勢，並結合外部搜尋結果一起回答：

  • 「幫我解釋今天發生了什麼事」
  • 「最近 Bitcoin 的走勢如何」
  • 「X 上的熱門 hashtag 有哪些」

程式碼能力

Grok 在程式開發上表現 中上水準，特別是在 Python、JavaScript、Go 等流行語言上：

🔍 觀察： Grok 語言支援廣度略遠落後於 GPT-5 和 Claude 5，但在 Python 與 Go 上表現可圈可價。

Grok 1.5 — 基礎版本

Grok 1.5 發布於 2025 年，是早期版本。主要改進包括推理鏈延長與多語言支援，但仍缺乏語音對話與圖像生成功能。

如何使用 Grok？

  • X Premium 訂閱 — 在 X 平台訂閱 Premium 即可使用 Grok 對話功能
  • API — 透過 xAI API 整合到自己的應用程式
  • 網頁版 — 直接造訪 grok.com 使用

程式碼範例 — Grok API

import requests

GROK_API_KEY = "your-api-key"
url = "https://api.x.ai/v1/chat/completions"

headers = {
    "Content-Type": "application/json",
    "Authorization": f"Bearer {GROK_API_KEY}",
}

payload = {
    "model": "grok-2.5",
    "messages": [
        {"role": "system", "content": "你是一個友善的 AI 助手"},
        {"role": "user", "content": "解釋一下什麼是 Web 3.0？"}
    ],
    "stream": False,
}

response = requests.post(url, headers=headers, json=payload)
print(response.json()["choices"][0]["message"]["content"])
