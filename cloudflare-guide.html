Cloudflare 功能詳解：CDN、DNS、SSL、WAF、Workers 與 Pages

2026-09-14 · 15 分鐘閱讀
Cloudflare CDN DNS 網站加速 教學
🎯 重點摘要：Cloudflare 是全球最大的邊緣網路平台，提供 CDN 加速、DNS 解析、SSL/TLS 加密、WAF 防護、DDoS 防禦、Cloudflare Workers 伺服函數、Pages 靜態站部署、Tunnel 內網穿透等服務。無論是個人部落格、電子商務網站抑或是企業應用，都能透過 Cloudflare 提升效能、安全性與可靠性。

Cloudflare 是什麼？

Cloudflare, Inc. 是一家美國雲端服務公司，創立於 2009 年。它以「全球最大的邊緣網路」為定位，透過在全球 300 多個據點部署的 CDN 節點，將用戶流量引導到距離最近的邊緣伺服器，實現網頁加載速度的顯著提升。

Cloudflare 的服務以 DNS 為入口 — 用戶只需將域名的 Nameserver 切換為 Cloudflare 提供的地址，即可自動享受 CDN 加速、DDoS 防護、SSL 加密等功能，無需修改伺服器或程式碼。

主要功能介紹

1. CDN（Content Delivery Network）

Cloudflare 的 CDN 會自動將你的網站靜態資源（HTML、CSS、JS、圖片等）快取到全球 300 多個邊緣資料中心。當用戶訪問你的網站時，Cloudflare 會將請求導向距離最近的邊緣伺服器，大幅減少延遲。

操作方法：

  • 將域名 Nameserver 切換為 Cloudflare 提供的地址（例如 ns1.cloudflare.com、ns2.cloudflare.com）。
  • 在 Cloudflare Dashboard 的「Speed」→「Optimization」中開啟「Auto Minify」（自動壓縮 CSS/JS/HTML）。
  • 在「Caching」→「Configuration」中設定快取等級（Cache Level）與 TTL。
  • 使用「Purge Cache」按鈕清除快取，當網站更新內容時立即生效。
💡 小技巧：初次啟用 CDN 時，建議將「Development Mode」開啟，這樣修改過的檔案會立即生效，無需等待快取過期。

2. DNS 管理

Cloudflare 提供快速、安全的 DNS 解析服務，解析速度通常低於 1ms，遠勝於一般註冊商提供的 DNS。

操作方法：

  • 在「DNS」標籤中點擊「Add record」，新增 A、AAAA、CNAME、MX、TXT、SRV 等類型的 DNS 記錄。
  • 切換「Proxy status」為「Proxied」（橘色雲朵 ✅），流量會經由 Cloudflare 節點；選「DNS only」（灰色雲朵），直接解析到伺服器。
  • 支援「DNS 重試」與「健康檢查」，當伺服器離線時自動切換備用 IP。
💡 小技巧：對於不需 CDN 加速的郵件 MX 記錄，請務必設定為「DNS only」（灰色雲朵），否則可能會影響郵件寄送。

3. SSL/TLS 加密

Cloudflare 提供免費的 SSL 憑證，支援 Let's Encrypt 與自有憑證上傳。啟用 SSL 後，網站連線從 HTTP 自動升級為 HTTPS。

操作方法：

  • 在「SSL/TLS」→「Overview」中選擇加密模式：Full（推薦）、Full (strict)、Flexible、Off。
  • 進階設定：在「Edge Certificates」中啟用「Always Use HTTPS」強制重定向。
  • 可上傳自有 SSL 憑證，或使用 Cloudflare 自動發行的憑證。

4. WAF（Web Application Firewall）

Cloudflare 的 WAF 會檢查進入網站的所有 HTTP 請求，阻擋 SQL 注入、XSS、CSRF 等常見攻擊。

操作方法：

  • 在「Security」→「WAF」中開啟 WAF 開關。
  • 選擇適用的規則集（例如 OWASP Core Ruleset 來防護常見漏洞）。
  • 可自訂規則：在「Tools」→「IP Access Rules」中封鎖或允放特定 IP 位址。

5. DDoS 防護

Cloudflare 在邊緣層攔截 DDoS 攻擊，保護起源伺服器不被壓垓。

操作方法：

  • 在「Security」→「DDoS」中設定防護等級（Under Attack、High、Medium、Low、Off）。
  • 「Under Attack」模式會針對可疑流量顯示挑戰驗證頁（JavaScript Challenge）。
  • 「Security Level」設定可以根據來路 IP 的信譽分數自動判斷是否顯示驗證。

6. Cloudflare Workers

Cloudflare Workers 是一種在邊緣運行的伺服函數平台，基於 V8 JavaScript 引擎。你可以撰寫 JavaScript、TypeScript、Rust、C 等語言部署到 Cloudflare 全球邊緣，實現毫秒級延遲的伺服端邏輯。

操作方法：

  • 在 Cloudflare Dashboard 點擊「Workers & Pages」→「Create」。
  • 使用線上編輯器編寫程式碼，或透過 wrangler CLI 工具本地開發：
// 基本 Worker 範例
export default {
  async fetch(request, env, ctx) {
    return new Response("Hello from Cloudflare Workers!", {
      headers: { "content-type": "text/plain" }
    })
  }
}
# 使用 Wrangler CLI 部署
npm install -g wrangler
wrangler login
wrangler deploy
💡 Pro 提示：Workers 支援 TypeScript、Rust、Python 等多種語言，並可與 Cloudflare 的 KV、D1、R2 等資料庫服務整合，非常適合打造 API 閘道、身份驗證、A/B 測試等功能。

7. Cloudflare Pages

Cloudflare Pages 是一個 Jamstack 靜態站託管平台，原生支援 Next.js、Nuxt.js、Vue、React、Svelte 等框架，並與 Git 整合實現自動部署。

操作方法：

  • 在「Workers & Pages」→「Create」→「Pages」，選擇你的 Git 提供商（GitHub、GitLab、Bitbucket）。
  • 選擇要部署的倉庫與分支，設定構建命令（例如 npm run build）與輸出目錄（例如 dist）。
  • 每次推送 Git 時，Pages 會自動觸發構建與部署。
💡 小技巧：Cloudflare Pages 與 Workers 無縫整合，可以在 Pages 專案中添加 Custom Domains，並自動配置 SSL。

8. Cloudflare Tunnel

Cloudflare Tunnel（原名 Argo Tunnel）讓你無需公開伺服器 IP，即可將內部網站透過 Cloudflare 反向代理暴露到公網。非常適合開發環境、內網服務穿透。

操作方法：

  • 安裝 Tunnel 客戶端：從 官方文檔 下載 cloudflared 二進制。
  • 建立 Tunnel：cloudflared tunnel create my-tunnel。
  • 設定路由：cloudflared tunnel route dns my-tunnel mydomain.com。
  • 在 DNS 中會自動新增 CNAME 紀錄，指向 Cloudflare 的任何閘道。
💡 Pro 提示：Tunnel 會加密所有的進出流量，無需在防火牆開放任何入站連接埠，極大提升安全性。

9. R2 物件存儲

Cloudflare R2 是一個 S3 兼容的物件存儲服務，與 Cloudflare 的 CDN 無縫整合，下傳費用為零（嫌免費額度內）。

操作方法：

  • 在「R2」標籤中點擊「Create bucket」，建立存儲桶。
  • 透過 Cloudflare Dashboard 上傳文件，或使用 S3 API 工具（如 awscli）操作。
  • 搭配 Workers，可實現圖片處理、私有文件訪問控制等進階應用。

10. Analytics 與日誌

Cloudflare 提供豐富的流量分析與安全日誌，幫助你了解網站的訪問情況與攻擊情況。

操作方法：

  • 在「Analytics」→「Dashboard」查看請求量、頻寬、快取命中率等指標。
  • 在「Security」→「Events」查看封鎖的攻擊請求詳情。
  • 啟用「Logs」→「Logpush」，將日誌推送到雲端存儲（如 AWS S3、Google Cloud Storage）。

快速入門五步驟

  1. 註冊帳號：前往 Cloudflare Dashboard 註冊並登入。
  2. 新增網站：點擊「Add a site」，輸入你的域名。
  3. 切換 Nameserver：前往域名註冊商，將 NS 记录改為 Cloudflare 提供的地址。
  4. 等待解析：通常在幾分鐘到 48 小時內生效，DNS propagation 可以透過 nslookup 檢查。
  5. 啟用功能：在 Dashboard 中開啟 CDN、SSL、Auto Minify 等功能。

常見問題答答

Q1. Cloudflare 會存取我的網站內容嗎？
A1. 不會。Cloudflare 僅作為反向代理，所有流量會加密傳輸，不會存留用戶的敏感數據。

Q2. 如何確認 Cloudflare 是否生效？
A2. 可使用 dig +short NS yourdomain.com 檢查 Nameserver，或訪問網站觀察 HTTP 標頭中的 Server: cloudflare。

Q3. Cloudflare 是否支援 HTTP/3？
A3. 是的，Cloudflare 提供 HTTP/3 支援（預設開啟），可在「Network」→「HTTP/3」中確認。

💡 最後提醒：Cloudflare 是工具，正確配置可以顯著提升網站速度、安全性與可用性。建譣先從 Free 方案開始體驗，逐步嘗試 Workers、Pages、Tunnel 等進階功能。
