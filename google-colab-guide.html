Google Colab 完整攻略：雲端 Jupyter Notebook 介紹、功能與實戰指南

2026-10-05 · 8 分鐘閱讀

隨著人工智慧與機器學習的發展，擁有強大算力的運算環境變得越來越重要。然而，對於初學者或學生來說，配置高效能 GPU 的電腦成本高昂，而 Google Colab（全名 Colaboratory）的出現，完美解決了這個痛點。

Google Colab 是一個基於雲端的 Jupyter Notebook 環境，讓任何人都能透過瀏覽器撰寫與執行 Python 程式碼，完全不需要設定環境，並提供免費的 GPU 與 TPU 資源。本文將深入介紹 Colab 的特色、基本使用方法以及進階開發技巧。

什麼是 Google Colab？

Google Colab 是由 Google Research 所開發的免費產品。它可以想成是「運行在 Google 伺服器上的 Jupyter Notebook」。它有以下三大核心優勢：

  • 零設定（Zero Configuration）： 打開瀏覽器即可開始寫 Python，無需煩惱安裝環境變數或套件依賴。
  • 免費 GPU/TPU 加速： 提供免費的 NVIDIA GPU (如 T4、L4) 與 Google 自研的 TPU，對於深度學習訓練來說是一大福音。
  • 輕鬆共享與協作： 檔案直接儲存在 Google Drive，你可以像分享 Google 文件一樣分享程式碼，甚至與他人協同編輯。

1. 初探 Google Colab 介面與基本操作

建立與儲存筆記本

前往 Colab 首頁，登入你的 Google 帳號。點選「新增筆記本」即可建立一個新的 .ipynb 檔案。預設情況下，這些檔案會自動儲存到你 Google Drive 內的 Colab Notebooks 資料夾中。

程式碼儲存格 (Code Cell) 與 文字儲存格 (Text Cell)

與一般的 Jupyter Notebook 相同，Colab 支援兩種主要的儲存格：

  • Code Cell： 用來撰寫 Python 程式碼。按下 Shift + Enter 即可執行並在下方顯示結果。
  • Text Cell： 用來撰寫說明文件，支援完整的 Markdown 語法（包含 LaTeX 數學公式：$E=mc^2$）。

2. 開啟 GPU / TPU 加速運算

Colab 最吸引人的功能莫過於免費硬體加速。要開啟 GPU 或 TPU，請依照以下步驟：

  1. 點擊頂部選單欄的 「執行階段」(Runtime)。
  2. 選擇 「變更執行階段類型」(Change runtime type)。
  3. 在「硬體加速器」(Hardware accelerator) 的下拉選單中，選擇 T4 GPU 或 TPU，然後點擊儲存。

你可以透過以下 Python 程式碼確認是否成功分配到 GPU：

!nvidia-smi

這行指令會顯示你分配到的 GPU 型號以及當前的記憶體使用狀態。

3. 檔案操作與 Google Drive 整合

因為 Colab 的執行環境是拋棄式的（閒置過久或超過使用時限，虛擬機就會被重置），任何儲存在虛擬機本機的檔案都會消失。因此，將資料持久化存儲至 Google Drive 是必備技巧。

掛載 Google Drive

你可以使用以下程式碼將 Google Drive 掛載至 /content/drive 目錄下：

from google.colab import drive
drive.mount('/content/drive')

執行後會彈出授權視窗，授權成功後，你就可以像操作本地磁碟一樣讀寫 Google Drive 裡的檔案：

import pandas as pd
# 讀取 Google Drive 中的 CSV 檔案
df = pd.read_csv('/content/drive/MyDrive/dataset.csv')
print(df.head())

上傳與下載檔案

如果你不想掛載整個 Drive，也可以使用 Colab 內建的方法臨時上傳或下載檔案：

from google.colab import files

# 上傳檔案 (會彈出檔案選擇視窗)
uploaded = files.upload()

# 下載檔案
files.download('model_weights.h5')

4. 安裝套件與使用系統指令 (Magic Commands)

雖然 Colab 已經預先安裝了 numpy, pandas, matplotlib, tensorflow, pytorch 等主流資料科學套件，但有時你還是需要安裝其他自訂套件。你可以使用 ! 符號來執行 Linux shell 指令：

# 安裝 Python 套件
!pip install transformers xgboost

# 複製 GitHub 儲存庫
!git clone https://github.com/huggingface/transformers.git

# 查看當前目錄檔案
!ls -la

此外，Colab 也支援 IPython 的 Magic Commands（以 % 開頭），例如：

  • %cd /content/drive/MyDrive：切換當前工作目錄。
  • %timeit：測試一行程式碼的執行時間。
  • %%writefile script.py：將該儲存格的內容寫入名為 script.py 的檔案中。

5. Colab 實用進階技巧

A. 防止 Colab 斷線 (防呆機制)

免費版的 Colab 如果在網頁閒置超過 90 分鐘，就會自動斷開連接並回收資源。一個常見的工程師小撇步是打開瀏覽器的「開發者工具」(Console)，輸入以下 JavaScript 程式碼來定時點擊頁面：

function ConnectButton(){
    console.log("Connect pushed"); 
    document.querySelector("#top-toolbar > colab-connect-button").shadowRoot.querySelector("#connect").click() 
}
setInterval(ConnectButton, 60000);
請注意，Google 可能會偵測並阻擋過度頻繁的自動點擊腳本，請謹慎使用。

B. 與 GitHub 整合

Colab 完美整合了 GitHub。你可以：

  • 在 Colab 首頁選擇「GitHub」標籤，直接讀取並開啟任何公用 Repository 的 .ipynb 檔案。
  • 在筆記本編輯介面中，點擊 檔案 -> 在 GitHub 中儲存副本，直接將筆記本推送到你的 GitHub 儲存庫中。

C. 顯示互動式圖表

除了傳統的 matplotlib，Colab 對於 plotly 或 altair 這類互動式視覺化套件的支援度極高。搭配 Colab 特有的 @param 註解，還能直接在右側生成簡易 UI：

#@title 設定訓練參數
learning_rate = 0.01 #@param {type:"number"}
epochs = 100 #@param {type:"slider", min:10, max:500, step:10}
print(f"學習率: {learning_rate}, 訓練週期: {epochs}")

6. Colab Pro 與限制 (Limitations)

雖然免費版極度佛心，但也有其硬性限制：

  • 最長執行時間： 免費版單次實例最多存活 12 小時。
  • 資源配額： GPU 分配並非保證，且當使用量太大時，會被系統限制配額 (Quota Limit)。
  • 記憶體： 免費版提供約 12GB 的系統記憶體。

對於需要更長訓練時間、更多記憶體（High-RAM）或保證獲得強大 GPU（如 A100）的專業用戶，Google 提供了 Colab Pro 與 Colab Pro+ 的付費訂閱服務。

結語

Google Colab 大幅降低了進入機器學習與資料科學領域的門檻。無需繁雜的硬體配置，透過瀏覽器便能即刻開啟高效能的程式開發之旅。無論你是正在上課的學生、嘗試新演算法的 AI 工程師，還是需要快速驗證想法的開發者，Colab 都是你不可或缺的強大工具。
